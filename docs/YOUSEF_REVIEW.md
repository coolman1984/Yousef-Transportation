# Yousef review

**Summary: 6 Blockers / 11 Important / 2 Nice-to-have.** Recommendation: close the security, recovery and installer gates, then ship only the assisted office pilot. Monetary settlement additionally needs B4 fixed. Store-level guide/support/licensing parity is unfinished; the pilot contract explicitly permits manual support and licensing (`Yousef-Transportation/LAUNCH_SCOPE.md:43`). Full factory compliance needs the Important items too.

Reviewed local snapshots on 2026-10-11: Yousef `f38f17a`, Apps-Factory `9c97ef8`, Store `bdf3440`. Paths below are workspace-relative. Existing strengths: server write guards, category scopes, correction journal, native import/export, historical-rate machinery, automatic verified database snapshots and clean-folder recovery. ## Blockers

1. **B1 — Read permissions do not protect `/api/state`.** `Yousef-Transportation/server/app.py:588` requires login but no page permission; `server/app.py:221` removes rates/contact numbers only. `server/store.py:254` returns all entity lists within category scope. Reproduced: projecting state with **zero permissions** still returns trip destinations and driver names. Filter entities/fields by permitted workflows and test restricted users calling the endpoint directly. **Reuse:** `Store/server/app.py:475` permission-gated reads and `Apps-Factory/packages/af-access/af_access.py`; requirement `Apps-Factory/RULES.md:20`.

2. **B2 — Windows users can bypass application security through local files.** `Yousef-Transportation/installer/trip-orders.iss:52` grants `users-modify` over the entire data tree, including databases and raw signing keys (`server/node.py:90`, `server/node.py:108`). Any other local Windows user can read keys or modify records outside app roles. Restrict access to the designated operator/service account, or explicitly validate a single trusted Windows-account deployment. **Reuse:** local-file/deployment checks from `Apps-Factory/docs/SECURITY_TEST_PLAYBOOK.md` and `Apps-Factory/RULES.md:34`. **Do not copy Store's ACL:** `Store/installer/store.iss:60` shares this weakness.

3. **B3 — Default installation exceeds the one-PC pilot boundary.** `Yousef-Transportation/config.json:3` binds every interface; `installer/trip-orders.iss:64` opens the firewall on **all profiles**. Browser traffic uses HTTP (`server/app.py:1202`, `server/app.py:1220`); cookies lack `Secure` (`server/app.py:473`). Moreover, an entirely invalid network allowlist broadens access to private ranges (`server/app.py:306`). Default the office-only candidate to loopback, disable/unconfigure optional connectivity, and reject invalid allowlists; validate TLS/trust before offering LAN access. **Reuse:** `Store/installer/store.iss:75` private/domain firewall restriction and `Apps-Factory/RULES.md:36` deployment checks.

4. **B4 — Historical zero-rate periods are silently repriced (monetary scope only).** `Yousef-Transportation/server/pricing.py:55` treats zero as never configured; `server/pricing.py:62` records history only for nonzero previous rates. Reproduced: 10 → 0 on September 1 → 20 on October 1 changes September's rate from 0 to 20. `server/reports.py:35` then changes historical settlement totals. Distinguish unset from zero and preserve every effective interval; prove report/Excel/Word agreement. **Reuse:** monetary validation patterns in `Store/tests/test_invariants.py` and `Store/server/money.py`; preserve the transport tariff model. Operational-only shipment must explicitly exclude settlement (`Yousef-Transportation/LAUNCH_SCOPE.md:7`).

5. **B5 — Backup retries can publish inconsistent data/history.** `Yousef-Transportation/server/backup.py:214` tries three times to obtain an unchanged journal watermark, but exhaustion falls through to publication at `server/backup.py:227`; auth is copied later at `server/backup.py:225`. Under concurrent writes the three databases can represent different moments, despite valid individual checksums. Abort on exhaustion and capture a coherent account/business/history boundary. **Reuse:** failure and recovery drills in `Store/tests/test_release.py`, archive validation patterns in `Store/server/backup.py`; retain Yousef's journal-specific restore semantics.

6. **B6 — Installed-candidate and field acceptance remain unproven.** `Yousef-Transportation/.github/workflows/build.yml:68` smoke-tests the build folder, never the actual installed/updated/uninstalled product; its explicit test list at line 45 also omits `tests/test_access_gate.py`. Launch gates remain pending (`LAUNCH_SCOPE.md:49`), as do clean-device/customer evidence (`Apps-Factory/examples/trip-orders-product.json:45`). Before shipping: run installed core journey, N-1 upgrade, restart/retry, uninstall retention and second clean Windows-PC restore; record commit, installer checksum and workflow, then customer acceptance and scope/support agreement. **Reuse:** `Store/.github/workflows/windows.yml:40`, `Store/tools/journey_exe.py`, `Apps-Factory/templates/RELEASE_EVIDENCE.md`. Verify required branch checks separately; local files cannot establish branch protection.

## Important

1. **I1 — Guide exists, but factory guide parity is missing.** `Yousef-Transportation/js/views/help.js:5` supplies eight FAQs; `js/shell.js:337` supplies a navigation tour. Preferences are browser-wide (`js/prefs.js:7`), not server-saved role-course progress. Add transport-specific first-day courses, actionable problem entries, coach/context help, independent guide language and browser resume checks. **Reuse:** `Store/server/assist.py:233`, `Store/web/js/guide.js:80`, `Store/guide/catalogue.json`, and `Apps-Factory/scripts/vendor_guide.py`; standards `Apps-Factory/RULES.md:65`.

2. **I2 — No consented telemetry integration.** Yousef's startup imports/wiring (`Yousef-Transportation/server/app.py:30`, `server/app.py:160`) and settings tabs (`js/views/settings.js:11`) have no consent or telemetry service. Add installation/person decisions, withdrawal/purge, allowlisted events and bounded offline delivery, off until consent and receiver configuration exist. Local business auditing is not telemetry consent. **Reuse:** `Store/server/assist.py:90`, `Store/web/js/guide.js:37`, `Store/tests/test_privacy.py:43`; vendor through `Apps-Factory/scripts/vendor_consent.py` and `vendor_telemetry.py`.

3. **I3 — No “report a problem” flow or payload preview.** `Yousef-Transportation/js/views/help.js:10` offers only tour/slides; no shared reporting action exists in the shell. Add every-page reporting, redaction, diagnostic preview and confirmation bound to the exact payload, plus queued/sent/retry states. **Reuse:** `Store/server/assist.py:419`, `Store/web/js/guide.js`, `Store/tests/test_privacy.py:154`, `Apps-Factory/packages/af-telemetry/af_telemetry.py`. **Reuse caveat:** Store requires tracking consent for reports (`Store/server/assist.py:440`), whereas `Apps-Factory/RULES.md:81` allows reports without it; adapt to that rule rather than copying the restriction.

4. **I4 — Crashes stay local; factory-hub delivery is absent.** `Yousef-Transportation/server/app.py:526` writes traceback/activity only; `js/core.js:21` only logs caught listener failures. Add privacy-safe server/browser fingerprints and nonblocking relay delivery. Never send current raw logs: they include user names, request paths and exception details. **Reuse:** `Store/server/assist.py:360`, `Store/server/assist.py:494`, `Store/web/js/guide.js:49`, `Apps-Factory/templates/telemetry-relay/src/worker.js` and `Apps-Factory/apps/control-center`. Provision receiver/token and prove hub ingest/ack; local source is not live service evidence.

5. **I5 — No licence/trial or online activation implementation.** `Yousef-Transportation/server/app.py:196` exposes a licence notice, not entitlement enforcement; neither service wiring nor settings (`js/views/settings.js:11`) provides activation. The manifest currently specifies manual contract (`Apps-Factory/examples/trip-orders-product.json:23`). For wider sale, add signed device-bound trial/monthly/permanent codes, expiry-safe read/export/backup, request preview, persisted polling/retry and manual fallback. Register `trip-orders` in Licence Studio. **Reuse:** `Store/server/licence.py`, `Store/server/trial.py:105`, `Store/web/js/app.js:209`, `Store/tests/test_licence_types.py`; `Apps-Factory/scripts/vendor_licence.py` and `templates/telemetry-relay/src/licence.js`. Worker transports codes; trusted local Studio signs them, never the Worker (`templates/telemetry-relay/README.md:54`). Deployment remains unverified.

6. **I6 — “Verified backup” does not verify required attachments.** `Yousef-Transportation/server/backup.py:110` verifies database parts only; the uploads manifest contains counts (`server/backup.py:235`). Reproduced: deleting a backed-up photo leaves `verify_set()['ok'] == True`. Secondary upload-copy failures are discarded (`server/backup.py:290`); `server/nodectl.py:231` returns success even after skipping damaged photos. Include required attachment inventory/checksums and explicit incomplete recovery status; validate same-size existing destination files too (`server/nodectl.py:220`). **Reuse:** archive completeness/checksum patterns in `Store/server/backup.py` and clean-restore evidence template `Apps-Factory/templates/RELEASE_EVIDENCE.md`. Photos remain outside the pilot promise unless accepted.

7. **I7 — Arabic dictionaries do not cover errors and installation.** `Yousef-Transportation/js/core.js:104` displays English server messages; `js/views/auth.js:53` exposes them on failed login. Link pages are hardcoded English (`server/app.py:455`), backup types show raw identifiers (`js/views/datatab.js:32`), and installer is English-only (`installer/trip-orders.iss:43`). Return stable translated error keys, localize types/link pages/installer, and run a nontechnical Arabic reading pass. **Reuse:** `Store/server/app.py:367`, `Store/web/js/i18n.js`, `Store/installer/store.iss:35`, `Apps-Factory/packages/af-guide/style/ar-lexicon.json`.

8. **I8 — Junk JSON becomes a crash and can expose exception details.** `Yousef-Transportation/server/app.py:488` accepts any JSON type; handlers such as login (`server/app.py:754`) immediately call `.get`. An array/null produces an unhandled exception, with exception text returned to the caller (`server/app.py:533`). Validate object bodies/types and return a generic localized error plus safe incident ID. **Reuse:** `Store/tests/test_fuzz.py`, `Store/server/assist.py:69`, `Store/server/app.py:372` error handling patterns; add transport-specific regression cases.

9. **I9 — Startup retry button is blocked by CSP.** `Yousef-Transportation/js/app.js:22` renders inline `onclick`, forbidden by `server/app.py:199` (`script-src 'self'`). Bind a listener after rendering and test a failed startup followed by retry. **Reuse:** event-listener and safe rendering patterns in `Store/web/js/ui.js` and `Store/web/js/app.js`.

10. **I10 — Custom signing/key encryption conflicts with factory policy.** `Yousef-Transportation/server/ed25519.py:1` implements signing in Python and explicitly lacks constant-time signing (`line 8`); `server/nodectl.py:56` implements a custom encryption stream for key exports. Replace with maintained cryptographic implementations and versioned, authenticated export formats with backwards-compatible recovery. **Reuse:** `Apps-Factory/packages/af-license/af_license/core.py:16`, `Apps-Factory/apps/licence-studio/licence_studio/service.py:261`; `Apps-Factory/RULES.md:102` forbids handwritten crypto. The factory's vendored public-key verifier is not a substitute for node signing/encryption.

11. **I11 — Factory accessibility/performance/style release proof is missing.** `Yousef-Transportation/js/views/settings.js:7` embeds colours and inline styles; CSP permits inline styles (`server/app.py:199`). Token tests (`tests/test_design.py:65`) do not establish axe, CPU-budget or complete Arabic/English browser acceptance. Move presentation into tokens/classes, run the factory probe, and inspect screenshots/keyboard flows. **Reuse:** `Store/ui-lab.config.json`, `Store/docs/ui-lab/REPORT.md`, `Apps-Factory/tools/ui-lab/probe.mjs`; gates `Apps-Factory/RULES.md:58`.
